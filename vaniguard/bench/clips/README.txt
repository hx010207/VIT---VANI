This directory holds real-audio validation clips recorded on phone microphones.
See bench/real_audio_validation.py for recording instructions and expected filenames.

Required files:
- clip_a_normal.wav: Normal grocery transfer instruction
- clip_b_urgent.wav: Urgent stressed instruction with urgency keywords
- clip_c_coercion.wav: Digital-arrest coercive script
- clip_d_suspicious_word.wav: Normal instruction with one suspicious keyword

Format: WAV, 16kHz sample rate, mono, 10 seconds each.
